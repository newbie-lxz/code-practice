# B站弹幕情感分析项目文件讲解

## 1. 项目整体流程

项目研究学习区与生活区视频弹幕的情感差异。完整流程为：

```text
输入两个 BV 号
-> 采集视频信息与弹幕
-> 清洗和中文分词
-> 构造词级、字级、词典、篇章和细粒度情感信息
-> 比较四个机器学习模型
-> 使用最优模型预测
-> 人工复核不确定样本
-> 连续迭代三次
-> 第四轮输出最终结果
```

项目只保留 `.ipynb` 代码。正式运行使用 `src/`，`annotated_code/` 仅用于阅读。

## 2. 本次准确率改进

相较于原来的简单 TF-IDF、词典计数和最终规则，本次增加或调整了：

1. **最长情感短语优先匹配**
   - 匹配词典时优先选择长短语，并阻止范围重叠。
   - 例如“看不懂”作为完整负面短语处理，不再同时匹配“懂”。

2. **篇章与转折分析**
   - 按逗号、句号、问号等切分弹幕。
   - 识别“但是、不过、然而、可是、却、虽然、尽管”等连接词。
   - 转折后的内容权重更高，让主结论更接近中文真实表达。

3. **混合情感识别**
   - 同一句同时出现明显正面和负面表达时，标记为混合情感。
   - 防止一个“哈哈”或一个负面词直接覆盖整句。

4. **细粒度情感分析**
   - 输出情感类型：对象评价、自身情绪、认知状态、立场。
   - 输出情感对象和方面，例如讲解质量、理解难度、节奏效率、视听体验、娱乐趣味。

5. **词级和字级联合建模**
   - 使用 `jieba` 词级 TF-IDF。
   - 使用中文字级 2-4gram TF-IDF，增强对弹幕梗、短语和未登录词的识别。

6. **模型训练流程修正**
   - 保留测试集进行公平评估。
   - 评估完成后，用全部已标注数据重新训练最优模型，再预测真实弹幕。
   - 随机森林使用经过验证的深度、树数量和类别平衡参数。

7. **高精度最终纠错**
   - 只对含义较稳定的典型短语做最终纠错。
   - 这些规则不进入训练特征，因此不会因少量短语扰动整体模型指标。

8. **主动学习改进**
   - 每轮最多询问 100 条。
   - 已经人工标注过的文本不会重复询问。
   - 人工标签优先级最高。
   - 不确定、模型词典冲突、转折和混合情感样本优先复核。

当前验证结果：

- 最优模型：随机森林
- 准确率：约 79.82%
- 宏平均 F1：约 72.92%
- 负面召回率：约 55%

## 4. `src/` 正式代码

### `src/run_experiment.ipynb`

一键实验入口。负责：

- 让用户输入实验名和两个 BV。
- 调用爬虫。
- 连续执行四轮分析。
- 前三轮逐条询问人工标签。
- 将原始数据、结果和图表按实验名归档。

使用方法：用 VS Code 或 Jupyter 打开后点击 `Run All / 全部运行`。

### `src/crawler_bilibili.ipynb`

B站弹幕采集模块。负责：

- 从 BV 号提取视频信息和分 P 信息。
- 获取 `cid`。
- 请求并解析弹幕。
- 去重并限制每个视频最多保留 2500 条。
- 保存视频标题、播放量、互动量、弹幕文本等字段。

### `src/train_analyze.ipynb`

项目核心分析模块。负责：

- 清洗文本、加载词典和人工反馈。
- 生成词级 TF-IDF、字级 n-gram 和情感特征。
- 训练并比较朴素贝叶斯、逻辑回归、SVM、随机森林。
- 生成分类报告、混淆矩阵和模型对比结果。
- 对真实弹幕预测并进行篇章、混合情感和高精度终判。
- 输出分类弹幕、统计、诊断样本和人工复核样本。

### `src/make_sample_data.ipynb`

缺少 `data/danmu_sample_5000.csv` 时生成演示训练数据。它用于保证项目可运行，不替代真实人工标注数据。

## 7. `results/` 实验结果目录

每次完整实验会生成：

```text
results/实验名称/
  round_1/
  round_2/
  round_3/
  final_round_4/
```

前三轮用于主动学习；`final_round_4` 是最终汇报结果。

每轮主要文件：

- `danmu_predicted.csv`：完整逐条预测。
- `positive_comments.csv`、`neutral_comments.csv`、`negative_comments.csv`：按最终标签拆分。
- `model_metrics.csv`：四模型准确率和宏平均 F1。
- `classification_report_full.csv`：最优模型各类别精确率、召回率和 F1。
- `confusion_matrix.csv`：混淆矩阵。
- `partition_sentiment_stats.csv`：分区三类情感比例。
- `video_sentiment_stats.csv`：按 BV 统计。
- `confidence_summary.csv`：置信度统计。
- `low_confidence_samples.csv`：低置信样本。
- `conflict_samples.csv`：模型与词典冲突样本。
- `review_samples.csv`：本轮主动学习候选样本。
- `sentiment_type_stats.csv`：情感类型统计。
- `aspect_sentiment_stats.csv`：方面级情感统计。
- `mixed_sentiment_samples.csv`：混合情感样本。
- `analysis_summary.md`：自动摘要。
- `experiment_summary.txt`：实验输入与输出汇总。

## 9. 正确使用顺序

1. 安装依赖：

```powershell
python -m pip install -r requirements.txt
```

2. 打开 `src/run_experiment.ipynb`。
3. 点击 `Run All / 全部运行`。
4. 输入实验名和两个视频链接或 BV。
5. 前三轮按提示输入 `1`、`0`、`-1`。
6. 完成后查看：

```text
results/实验名称/final_round_4/
figures/实验名称/final_round_4/
```

7. 报告使用 `final_round_4` 中的新指标和图表，不再使用旧报告中的实验数字。
