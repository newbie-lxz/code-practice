# 人工反馈目录

本目录保存可跨实验重复使用的人工标签。

当前主要文件：

- `manual_labels_history.csv`：从历史实验中合并得到的人工标注，共 587 条不重复文本。

CSV 至少需要包含：

```text
text,review_label
```

标签规则：

- `1` 或 `正面`
- `0` 或 `中性`
- `-1` 或 `负面`

运行 `src/run_experiment.ipynb` 时，程序会自动读取本目录下所有 CSV，并将有效人工标签加入训练。相同文本出现多次时，以最后读取到的标签为准。

人工标签优先级最高：如果待预测弹幕与历史人工标注文本相同，最终结果会直接采用人工标签。
