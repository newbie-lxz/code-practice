## 复核方法

前三轮分别抽取 100 条模型低置信、词典冲突、转折或混合情感样本，由大模型根据完整弹幕语义标注：

- `1`：正面
- `0`：中性
- `-1`：负面

标注时优先考虑整句表达目的、语境、网络口语、调侃、反讽和转折后的主结论，不直接照抄模型预测。
