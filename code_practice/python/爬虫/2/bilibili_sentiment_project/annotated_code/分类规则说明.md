# 分类规则说明

最终标签不是由一个词或一个概率直接决定，而是按以下层次组合：

1. 人工标注拥有最高优先级。
2. 模型比较朴素贝叶斯、逻辑回归、SVM、随机森林，并选择宏平均 F1 最好的模型。
3. 模型输入包含词级 TF-IDF、字级 2-4gram TF-IDF 和经过验证的情感数值特征。
4. 最长短语匹配避免短词重复计分，例如“看不懂”不会再额外匹配“懂”。
5. 篇章分析提高转折后分句的权重，例如“讲得清楚，但是太快”重点考虑“太快”。
6. 同时含正负表达的弹幕标记为混合情感，不让单个“哈哈”或单个负面词覆盖整句。
7. 高精度短语只在最终判定层纠正典型误判，不进入训练特征，避免少量规则扰动整个模型。
8. 模型不确定、词典冲突和混合情感样本会优先进入人工复核。
