# code-practice

这是一个用于记录编程学习过程的练习仓库。内容按语言、课程练习和小项目分类，重点是基础语法、算法思维与项目实践。

## 目录导航

| 目录 | 学习内容 |
| --- | --- |
| `code_practice/C++/基础` | C++ 基础语法：变量、流程控制、数组、函数、指针、结构体、类与对象等。 |
| `code_practice/C++/进阶` | C++ 进阶练习，例如 STL、面向对象和更复杂的编程题。 |
| `code_practice/C++/csp` | CSP 认证题目与算法练习，包含题目代码、输入输出样例和不同语言的解法。 |
| `code_practice/c语言/1-5练习` | C 语言入门练习，覆盖基本输入输出、条件判断、循环和函数。 |
| `code_practice/c语言/6-11进阶` | C 语言进阶内容，包括数组、指针、结构体、文件操作等。 |
| `code_practice/c语言/课堂` | 课堂配套代码与随堂练习。 |
| `code_practice/c语言/ctf` | C 语言与安全方向的练习。 |
| `code_practice/c语言/勒索病毒大作业` | C 语言课程大作业相关代码与实验材料。 |
| `code_practice/python/1`、`2`、`3` | Python 基础语法练习：变量、分支、循环、函数、容器和常用模块。 |
| `code_practice/python/爬虫` | 网络爬虫、数据采集及 B 站弹幕情感分析项目。 |
| `code_practice/python/小项目` | Python 小项目，例如教务管理系统和购物车系统。 |
| `code_practice/python/ai` | AI 与大模型调用练习；其中只有 `AI_Partner` 是对外维护的完整项目。 |
| `code_practice/小游戏/扫雷` | 扫雷小游戏相关代码。 |
| `code_practice/git` | Git 学习记录与常用操作资料。 |
| `code_practice/vs2022 c++` | Visual Studio 2022 创建的 C++ 工程练习。 |

## 推荐阅读顺序

1. 从 C 或 Python 的基础练习开始，熟悉变量、条件、循环和函数。
2. 学习数组、指针、结构体、类与对象等语言特性。
3. 通过 CSP 题目和小项目练习算法与调试能力。
4. 再阅读爬虫、数据分析和 AI 项目，理解如何把基础知识用于完整程序。

## AI_Partner

`code_practice/python/ai/AI_Partner` 是一个基于 Streamlit 和 DeepSeek API 的网页聊天应用，支持多轮对话、本地历史会话、个性化人设和可选联网搜索。项目的安装与运行说明见 [AI_Partner README](code_practice/python/ai/AI_Partner/README.md)。

## 安全说明

仓库不会提交 `.env`、API Key、token、会话数据或本地缓存。运行需要 API Key 的项目时，请在本机创建自己的 `.env` 文件，不要将它上传到 GitHub。
